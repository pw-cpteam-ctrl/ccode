## 2026-07-31 (V1.1 발표일 기준 수집 + 자동 배포 통로)

### 받아올 날짜 (신규 기능 + 버그 수정)
- **전날 저녁 6시에 미리 공개되는 다음날 상품을 받지 못하던 문제 수정** — PC 시계가 아니라
  사이트에 올라와 있는 발표일 기준으로 변경, 평소 실행 시 가장 최신 발표일분을 자동 수집
  (기술: 상품 카드의 `data-guidance_date` 속성으로 발표일 목록 구성, `target-date.js` 분리,
  기존 `todayYYYYMMDD()` 일치 필터 폐기)
- **받을 발표일을 목록에서 골라 받는 실행 파일 추가** (`run-pick-date.bat`) — 건수와 함께 날짜를
  보여주고 번호로 선택, 엔터만 치면 최신
  (기술: `--pick` 모드, `readline` 번호 입력, 잘못된 입력 시 최신으로 진행)
- **특정 날짜 직접 지정 지원** (`--date=20260730`) — `-` `/` `.` 구분자와 공백 허용
  (기술: `normalizeDateArg`로 8자리 숫자 정규화)
- **결과 폴더 이름이 세계 표준시 기준이라 한국시간 오전 9시 이전 실행 시 어제 날짜 폴더에
  저장되던 버그 수정** — 폴더 이름을 받은 발표일로 지어 시계를 아예 쓰지 않게 변경
  (기술: `new Date().toISOString()` 기반 `OUT_DIR` 제거 → `toFolderName(target.date)`)
- **사이트에 없는 날짜를 지정하면 조용히 0건이 되던 동작 개선** — 이유와 받을 수 있는 날짜
  목록을 함께 안내
  (기술: `resolveTargetDate`가 실패 사유와 후보 목록을 반환)
- **결과 파일에 어느 발표일분인지 기록** (기존 파일과 호환)
  (기술: `output.json`에 `guidanceDate` 추가, 값이 있을 때만 기록하는 방식)

### 배포·업데이트 (구조 변경)
- **업데이트 배포 시 사람이 파일을 손으로 복사해야 했던 단계 제거** — 개발 저장소에 올리면
  그대로 배포됨
  (기술: Vercel `api/files.js`가 저장소의 이 폴더를 읽어 팀원용 파일만 JSON으로 제공,
  별도 배포 저장소 경유 폐기)
- **팀원 파일에서 개발 저장소 이름 노출 제거** — 배포 주소만 남음
  (기술: `update-source.js` 한 곳에 Vercel 주소만 보관, `codeload` zip 방식 폐기)
- **압축 해제 시 다른 프로젝트 파일이 팀원 폴더에 풀리던 문제 제거** — 필요한 파일만 내려받음
  (기술: 파일 단위 전송으로 전환, `tar`/`robocopy` 의존 제거)
- **업데이트가 결과물·설치된 라이브러리·로그인을 지우지 않도록 보장** — 받은 파일만 덮어씀
  (기술: 삭제 동작 없음, `output/`·`node_modules`·프로필 경로 미접근)
- **부분 적용으로 버전이 섞이는 상태 방지** — 받은 내용 전체를 검사한 뒤에만 쓰기 시작
  (기술: `validate()` 선행 검사, 폴더 밖 경로(`../`) 포함 시 거부)
- **업데이트 실패가 업무를 막지 않게 안내 정비** — "지금 버전으로 계속 사용 가능 + 화면 캡처해서
  담당자에게" 문구 출력 후 파일 미변경
  (기술: `update.js`의 `fail()` 공통 처리, 종료코드 1)
- **새 파일 추가 시 배포 목록 누락으로 팀원 쪽이 실행 불가가 되는 사고 방지** — 서버가 파일 간
  의존 관계를 스스로 점검해 빠지면 응답 실패
  (기술: `findMissingRequires()`가 `require('./…')` 대상 존재 여부 검사, 누락 시 500)
- **업데이트 실행 파일을 껍데기로 축소해 앞으로 수동 교체가 필요 없게 변경**
  (기술: `update.bat`은 `node update.js` 호출만 담당하고 배포 목록에서 제외 — CMD가 배치 파일을
  줄 단위로 읽어 실행 중 자기 덮어쓰기가 위험하기 때문. 노드 스크립트는 자기 갱신에 안전)
- **팀원용 문서 신설** (`사용법.md`) — 개발용 README와 분리
  (기술: README는 배포 목록에서 제외, 저장소 이름·내부 판단 근거 비노출)
- **불필요한 재배포 방지** — 이 폴더가 바뀔 때만 배포
  (기술: `vercel.json`의 `ignoreCommand`, 외부 라이브러리 미사용이라 설치 단계 생략)

### 안정성
- **버전 확인 스크립트가 주소 파일을 못 찾으면 검은 창에 오류가 쏟아지던 문제 수정** — 조용히
  넘어가 스크랩 실행을 막지 않음
  (기술: `check-update.js`의 `require` 예외 처리, `UPDATE_API` 없으면 확인 생략)
- **버전 판별 기준을 커밋 기록에서 파일 내용 해시로 변경** — 관계없는 커밋에 "새 버전 있음"이
  헛되게 뜨지 않음
  (기술: 파일 이름+내용 sha256 앞 12자, `?meta=1`로 가벼운 버전 조회 제공)
