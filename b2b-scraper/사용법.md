# 굿스마일 상품 가져오기 — 사용법

이 폴더 안의 파일을 더블클릭해서 쓰는 도구입니다. 명령어를 외울 필요는 없고,
아래 파일 3개만 알면 됩니다.

| 더블클릭할 파일 | 언제 쓰나 |
|---|---|
| `run.bat` | **평소.** 최신 발표일 상품을 자동으로 받아옵니다 |
| `run-pick-date.bat` | 지난 날짜 상품이 필요할 때. 날짜를 골라서 받습니다 |
| `update.bat` | "새 버전이 있습니다" 안내가 떴을 때 |

> 바탕화면에 바로가기를 만들어두면 편합니다. 파일 우클릭 → **바로가기 만들기** → 바탕화면으로
> 옮기고, 이름은 한글로 바꿔도 괜찮습니다. (예: "굿스마일 상품 가져오기")

---

## 평소 사용법

1. **`run.bat`** 을 더블클릭합니다.
2. 검은 창이 뜨고 진행 상황이 한국어로 표시됩니다. **여기에 뭘 입력할 필요는 없습니다.**
   - 처음 실행하면 준비 작업 때문에 1~2분 걸립니다. 그 다음부터는 빠릅니다.
3. 크롬 창이 뜹니다.
   - **로그인이 기억되어 있으면** 아무것도 안 해도 알아서 넘어갑니다.
   - **로그인 창이 뜨면** 그 창에서 굿스마일 아이디/비밀번호로 로그인만 하세요.
     엔터를 누르거나 창을 닫을 필요 없이, 로그인되면 자동으로 이어집니다.
4. 상품을 하나씩 받으면서 `✅ (상품명) 처리 완료` 가 쭉 올라갑니다.
5. 끝나면 **결과 폴더가 자동으로 열립니다.** (폴더 주소도 복사되어 있어서 붙여넣기 가능)
6. 원고 작성 페이지에서 **"B2B에서 오늘 상품 가져오기"** 버튼을 누르고, 방금 열린
   **날짜 이름의 폴더를 통째로 선택**하거나 그 폴더를 버튼 위로 **끌어다 놓으면** 됩니다.
   사진까지 한 번에 채워집니다.

### 받아지는 날짜에 대해

이 사이트는 **전날 저녁 6시쯤에 다음날 상품을 미리 공개**합니다.
그래서 `run.bat`은 "오늘 날짜"를 찾는 게 아니라 **사이트에 올라와 있는 가장 최신 날짜**를
받아옵니다.

- 아침에 실행 → 그날 상품
- 저녁 6시 이후에 실행 → **다음날 상품** (그래서 결과 폴더 이름이 내일 날짜일 수 있습니다.
  잘못된 게 아닙니다)

결과 폴더 이름은 **상품이 발표된 날짜**입니다. 같은 날짜를 다시 받으면 그 폴더 내용만
새로 채워지고, 다른 날짜 결과와 섞이지 않습니다.

## 지난 날짜 상품을 받고 싶을 때

**`run-pick-date.bat`** 을 더블클릭하면, 받을 수 있는 날짜를 이렇게 보여줍니다:

```
받을 수 있는 발표일:
  1) 2026년 7월 30일 — 18건   ← 가장 최신
  2) 2026년 7월 29일 — 12건
  3) 2026년 7월 28일 — 9건

번호를 고르고 엔터 (엔터만 치면 1번):
```

원하는 **번호를 누르고 엔터**를 치면 그 날짜 상품을 받습니다. 엔터만 치면 가장 최신 날짜로
진행됩니다.

> 아주 오래된 날짜는 목록에 안 나옵니다. 사이트 첫 화면에 남아있는 날짜만 받을 수 있어서
> 그렇습니다. 목록에 없는 날짜가 필요하면 담당자에게 말씀해주세요.

**이미 받아둔 날짜**를 다시 쓰고 싶을 때는 이 파일을 쓸 필요가 없습니다. 원고 작성 페이지의
가져오기 버튼에서 `output` 안의 그 날짜 폴더를 고르면 됩니다.

## 새 버전 안내가 떴을 때

`run.bat`을 실행했을 때 이런 안내가 지나갈 수 있습니다:

```
┌───────────────────────────────────────────────────────┐
│  새 버전이 있습니다.                                  │
│  이 작업이 끝난 뒤 update.bat 을 한 번 실행해주세요.  │
└───────────────────────────────────────────────────────┘
```

**지금 하던 작업은 그대로 끝까지 하세요.** 다 끝난 뒤에 `update.bat`을 한 번 더블클릭하면
됩니다. 몇 초면 끝납니다.

- 저장된 로그인, 지금까지 받아둔 `output` 폴더 결과물은 **업데이트해도 지워지지 않습니다.**
- 업데이트가 실패해도 **지금 버전으로 계속 사용할 수 있습니다.** 그때는 화면을 캡처해서
  담당자에게 보내주세요.

## 문제가 생겼을 때

| 증상 | 이렇게 해보세요 |
|---|---|
| "Node.js not found" 라고 나옴 | 안내에 적힌 주소(nodejs.org)에서 **LTS** 버전을 설치한 뒤 다시 더블클릭 |
| 로그인이 계속 안 되거나 이상하게 막힘 | **`reset-login.bat`** 더블클릭 → 저장된 로그인이 지워집니다 → 다시 `run.bat` 실행해서 새로 로그인 |
| 상품이 0건이라고 나옴 | 사이트에 아직 새 상품이 안 올라온 경우일 수 있습니다. 잠시 뒤 다시 시도해보고, 계속 그러면 화면 캡처해서 담당자에게 |
| 그 외 빨간 글씨 / 알 수 없는 오류 | **화면을 그대로 캡처해서 담당자에게 보내주세요.** 대부분 원인 안내가 함께 표시됩니다 |

검은 창에 영어 에러가 잔뜩 나와도 당황하지 않으셔도 됩니다 — 캡처해서 보내주시면 됩니다.
이 도구는 사이트에서 정보를 **읽어오기만** 하므로, 잘못 눌러서 사이트 쪽에 문제가 생기는
일은 없습니다.
