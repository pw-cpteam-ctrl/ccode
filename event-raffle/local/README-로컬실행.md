# 이벤트 추첨기 — 로컬 실행기

인스타그램 댓글 **수집**과 **추첨**을 프로그램 하나에서 끝내는 버전입니다.
파일을 내려받았다가 다시 올릴 필요가 없어요.

> 지금까지처럼 웹에서 엑셀을 올려 쓰는 방식([추첨기 웹페이지](https://ccode-delta.vercel.app/))도
> 그대로 됩니다. 이 폴더는 "수집까지 한 번에" 하고 싶을 때만 쓰는 추가 입구예요.

---

## 처음 한 번만 (설치)

### 1. Node.js 설치
[nodejs.org](https://nodejs.org/) 에서 **LTS** 버전을 받아 설치합니다(다음 → 다음으로 진행).
이미 다른 도구를 쓰고 있어 설치돼 있다면 넘어가세요.

### 2. `start.bat` 더블클릭
처음 실행하면 필요한 것들을 자동으로 내려받습니다. **몇 분 걸릴 수 있어요.**
검은 창이 뜨고 잠시 뒤 브라우저에 추첨기 화면이 열립니다.

### 3. 인스타 로그인 (한 번만)
화면 맨 위 **"인스타 로그인"** 버튼을 누르면 크롬 창이 뜹니다.
그 창에서 **직접 로그인**하세요(2단계 인증이 있으면 그것까지). 로그인이 끝나면
자동으로 감지해서 저장하고 창이 닫힙니다.

- 아이디·비밀번호를 프로그램이 대신 입력하지 않습니다. 사람이 직접 로그인한 상태를
  그대로 저장해두는 방식이라 인스타가 "자동 프로그램"으로 의심할 가능성이 낮아요.
- 저장된 로그인 정보는 **이 컴퓨터 안에만** 있습니다(`instagram-session.json`).
  깃허브에 올라가지 않도록 막아뒀어요.
- 며칠~몇 주 지나면 풀립니다. 그때 이 버튼을 다시 누르면 돼요.

## 매번 쓰는 법

1. **`start.bat` 더블클릭** → 브라우저에 추첨기가 열립니다
2. 맨 위 칸에 **인스타 게시물 주소**를 붙여넣습니다 (`.../p/...` 또는 `.../reel/...`)
3. 옵션을 고릅니다
   - **대댓글(답글)도 수집** — 답글까지 추첨 대상에 넣을 때. 느려집니다
   - **게시물 주인 댓글 제외** — 보통 켜두세요
   - **친구 소환(@) 댓글 2배** — 친구를 태그한 사람의 당첨 확률을 두 배로
4. **"댓글 수집 시작"** → 크롬 창이 뜨고 알아서 읽어옵니다 (댓글이 많으면 몇 분)
5. 끝나면 추첨기 화면에 참가자가 자동으로 채워집니다
6. **인스타에 표시된 댓글 수와 "수집 완료 N명"을 눈으로 비교**해주세요
7. 아래에서 조건을 걸고 추첨하면 됩니다

> ⚠️ 검은 창을 닫으면 프로그램도 꺼집니다. 다 쓸 때까지 열어두세요.

## 알아두면 좋은 것

**수집 인원이 인스타 댓글 수보다 적을 때**
- 답글은 기본적으로 안 셉니다 (옵션을 켜야 포함)
- 게시물 주인 댓글은 기본적으로 빠집니다
- 그래도 많이 차이 나면 화면의 "진행 상황"에 `⚠️ 읽지 못해 건너뛴 줄` 안내가 있는지
  보세요. 인스타가 화면 구조를 바꾼 신호일 수 있습니다

**댓글을 하나도 못 읽었다고 나올 때**
- 로그인이 풀렸을 가능성이 큽니다 → "인스타 로그인"을 다시 누르세요

**한 번에 너무 많이 긁지 마세요**
- 짧은 시간에 대량으로 수집하면 인스타가 계정을 일시 제한할 수 있습니다

**코드를 새로 받았으면 검은 창을 껐다 켜세요**
- 켜져 있는 동안에는 예전 코드로 계속 돌아갑니다

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `start.bat` | 더블클릭용 실행 파일 |
| `server.js` | 추첨기 화면을 띄우고 수집 작업을 실행 |
| `login-session.js` | 인스타 로그인 1회 → 로그인 상태 저장 |
| `collect-instagram.js` | 실제 댓글 수집 |
| `inject-collect-ui.js` | 로컬로 열었을 때만 추가되는 수집 패널 |
| `browser-stealth.js` | 자동 프로그램으로 의심받지 않게 하는 위장 |

- 추첨기 본체(`../index.html`)는 **한 글자도 고치지 않았습니다.** 로컬에서 화면을 보낼 때만
  수집 패널을 끼워 넣기 때문에, 웹에 올라간 추첨기는 지금까지와 똑같이 동작해요.
- `browser-stealth.js`는 같은 저장소 `sns-report-scraper`에서 실사용 검증된 것을 복사해온
  것입니다. 불러다 쓰지 않고 복사한 이유는 이 저장소가 "폴더 하나 = 프로젝트 하나,
  서로 참조하지 않는다" 규칙으로 운영되기 때문이에요. 고칠 일이 생기면 두 곳 다 손봐야 합니다.

## 댓글을 찾는 방법에 대해

화면에서 댓글을 찾아내는 방식은 기존에 쓰던 크롬 확장(인스타그램 댓글 추출기)의 방식을
그대로 옮겨왔습니다. 실사용에서 잘 걸러지는 것이 확인된 방식이라 새로 고안하지 않았어요.
핵심은 **클래스 이름에 매달리지 않는 것**입니다:

- 댓글 목록 → 페이지의 모든 목록 중 "시간표시 + 프로필링크"를 가장 많이 가진 목록을 고름
- 작성자 → 프로필 주소 모양인 링크 (`privacy`, `terms` 같은 안내 페이지는 제외)
- 본문 → 작성자 링크에서 위로 거슬러 올라가 시간표시를 품은 덩어리를 찾음

인스타가 클래스 이름을 난수로 바꿔도 이 구조 자체는 잘 바뀌지 않습니다.
본문을 못 읽는 경우에는 **아이디를 본문인 척 기록하지 않고 그 줄을 건너뛰며, 건너뛴
개수를 화면에 표시**합니다 — 일부만 수집됐는데 전부인 줄 알고 추첨하는 일을 막기 위해서예요.
