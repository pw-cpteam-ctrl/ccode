터미널 명령어 대신 이 화면에서 버튼으로 실행할 수 있게 만든 도구
⚠️ 이 화면은 이 컴퓨터 안에서만 동작해요. 다른 컴퓨터·팀원은 이 주소로 못 들어오고, 각자 자기 컴퓨터에서 이 프로그램을 따로 실행해야 해요. 로그인 정보도 이 컴퓨터 밖으로 전송되지 않고 여기 파일로만 저장돼요.

어느 브랜드를 볼까요?

불러오는 중...

1. 로그인 상태 확인

실적을 수집하려면 트위터/인스타그램에 로그인된 상태(세션)가 필요해요. 한 번 로그인해두면 며칠~몇 주 정도는 계속 쓸 수 있고, 풀리면 로그인 화면이 계속 뜨는 식으로 알 수 있어요 — 그럴 때 여기서 다시 로그인하면 돼요.

트위터 확인 중...
인스타그램 확인 중...

버튼을 누르면 이 컴퓨터에 실제 브라우저 창이 새로 뜰 거예요. 그 창에서 평소처럼 직접 로그인(2단계 인증 있으면 그것도 그대로)하고, 다 되면 아래 "로그인 완료했어요" 버튼을 눌러주세요.

⚔️ 게시글 맞대결

링크 넣은 글끼리만 1:1로 비교해요. 양쪽 게시일이 서로 달라도 됩니다. 기간 수집과 달리 넣어준 주소만 바로 열기 때문에 몇 주 전 글이어도 금방 끝나요.
예) 우리 이벤트 글 vs 경쟁사 이벤트 글 — 좋아요·리트윗·댓글이 나란히, 게시물 미리보기도 나란히 나옵니다.

X(트위터)·인스타그램 링크 둘 다 됩니다(섞어도 돼요). 한쪽만 넣어도 만들어져요.
※ 게시일이 다르면 먼저 올린 쪽이 더 오래 노출된 상태라, 리포트에 경과일이 같이 표시됩니다.
※ 인스타그램은 좋아요를 숨긴 게시물이면 좋아요 수를 못 읽어요(댓글 수만 나옴).

2. 실적 수집하기

자사(PW)와 경쟁사(BH)의 게시물을 모아서 비교 리포트를 만들어요. 인터넷을 오가며 실제로 읽어오는 거라 보통 몇 분 걸립니다.

3. 다시 수집하지 않고 리포트만 다시 만들기

방금 모아둔 데이터로 몇 초 만에 다시 만들어요(인터넷 접속 없음). 키워드만 바꿔서 다시 볼 때 쓰면 좋아요 — 수집은 통째로 해두고 볼 때만 거르는 구조라 몇 분짜리 재수집이 필요 없습니다.

4. 재고만 찍기 (SNS 수집 없이)

네이버 스토어의 지금 재고만 기록해요. SNS 수집(몇 분)과 로그인 없이 수십 초면 끝나요. 리포트의 재고 추이 그래프는 같은 상품이 2번 이상 기록돼야 나오니, 그래프를 보고 싶으면 며칠에 걸쳐 이 버튼을 몇 번 눌러두면 돼요. (SNS 수집을 할 때는 재고도 자동으로 같이 기록되니 그때는 따로 누르지 않아도 돼요)

5. 날짜가 떨어진 여러 기간 비교하기

예: 6/10~13, 6/18~22처럼 사이에 공백이 있는 여러 기간을 각각 "오늘 실적 수집"으로 미리 모아뒀다면, 그 기간들을 나란히 비교하는 표를 만들어요. 아래에 이미 수집해둔 기간을 "시작일_종료일" 형태로 한 줄씩 적어주세요(2개 이상).

6. 특정 계정 하나만 단독으로 보기

자사·경쟁사 비교가 아니라, 임의의 트위터 계정 하나만 골라서 그 계정 게시물 성과만 순위표로 보고 싶을 때 사용해요.

7. 노션으로 보내기

방금 만든 리포트의 표를 스크린샷이 아니라 진짜 노션 표로 만들어줘요(검색·정렬·편집 가능).

복사하기: 버튼 누르면 바로 클립보드에 복사돼요 — 노션 페이지에서 Ctrl+V만 누르면 끝(연동 설정 필요 없음).
자동 전송: 노션 연동을 미리 설정해뒀다면 클릭 한 번으로 전송돼요(처음 한 번은 새 페이지 생성, 그다음부턴 같은 페이지 내용만 갱신 — 노션에서 손으로 맞춘 칸 너비가 계속 유지돼요) — notion-config.json 파일이 없으면 실패 메시지가 떠요.
