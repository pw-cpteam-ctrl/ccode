로그인 관리

실적을 수집하려면 트위터/인스타그램에 로그인된 상태(세션)가 필요해요. 한 번 로그인해두면 며칠~몇 주 정도는 계속 쓸 수 있고, 풀리면 수집할 때 로그인 화면이 계속 뜨는 식으로 알 수 있어요.

버튼을 누르면 이 컴퓨터에 실제 브라우저 창이 새로 뜰 거예요. 그 창에서 평소처럼 직접 로그인(2단계 인증 있으면 그것도 그대로)하고, 다 되면 "로그인 완료했어요" 버튼을 눌러주세요.

이 화면은 이 컴퓨터 안에서만 동작해요. 다른 컴퓨터·팀원은 이 주소로 못 들어오고, 각자 자기 컴퓨터에서 이 프로그램을 따로 실행해야 해요. 로그인 정보도 이 컴퓨터 밖으로 전송되지 않고 여기 파일로만 저장돼요.

📊 기간 지정 SNS 비교

자사(PW)와 경쟁사(BH)의 게시물을 모아서 비교 리포트를 만들어요. 인터넷을 오가며 실제로 읽어오는 거라 보통 몇 분 걸립니다.

① 어느 기간을 볼까요?
방금 모아둔 데이터로 몇 초 만에 다시 만들어요(인터넷 접속 없음). 위 키워드·재고 표시가 그대로 적용되니, 키워드만 바꿔서 다시 볼 때 쓰면 좋아요.
이 기능 설명 자세히 보기
상품명은 게시물 본문에서 자동으로 뽑아 비슷한 것끼리 짝지어요. 표현이 다르거나 못 뽑은 글은 리포트의 "매칭 안 됨" 목록에 따로 남습니다 — 조용히 빠지지 않아요.
재고를 "같이 기록"으로 두는 걸 권합니다 — 재고는 지금 시점만 조회할 수 있어서, 안 찍고 지나간 날은 나중에 되돌릴 수 없어요.

⚔️ 게시글 맞대결

비교하고 싶은 글 링크만 넣으세요. 양쪽 게시일이 서로 달라도 됩니다. 기간 수집과 달리 넣어준 주소만 바로 열기 때문에 몇 주 전 글이어도 금방 끝나요.

이 기능 설명 자세히 보기 · 입력 지우기
X(트위터)·인스타그램 링크 둘 다 됩니다(섞어도 돼요). 한쪽만 넣어도 만들어져요.
게시일이 다르면 먼저 올린 쪽이 더 오래 노출된 상태라, 리포트에 경과일이 같이 표시됩니다.
인스타그램은 좋아요를 숨긴 게시물이면 좋아요 수를 못 읽어요(댓글 수만 나옴).

🔍 계정 하나 단독 보기

자사·경쟁사 비교가 아니라, 트위터 계정 하나만 골라서 그 계정 게시물 성과만 순위표로 보고 싶을 때 사용해요.

트위터 계정만 가능해요 · 기간이 길면 오래 걸립니다

📋 노션으로 보내기

방금 만든 리포트의 표를 스크린샷이 아니라 진짜 노션 표로 만들어줘요(검색·정렬·편집 가능).

두 버튼의 차이 보기
복사하기: 버튼 누르면 바로 클립보드에 복사돼요 — 노션 페이지에서 Ctrl+V만 누르면 끝(연동 설정 필요 없음).
자동 전송: 노션 연동을 미리 설정해뒀다면 클릭 한 번으로 전송돼요(처음 한 번은 새 페이지 생성, 그다음부턴 같은 페이지 내용만 갱신 — 노션에서 손으로 맞춘 칸 너비가 계속 유지돼요). notion-config.json 파일이 없으면 실패 메시지가 떠요.
