# 메가하우스 업로드 보드

메가하우스 월간 업로드 한 회차(D-7 프리뷰 → D-1 발주서 → D-0 스토어 오픈 → D+14 리마인드 → D+30 마감임박)를
한 화면에서 관리하는 도구. 빌드/서버 없이 `index.html`을 GitHub Pages로 연다. 메가하우스 전용(굿스마일·부시로드 제외).

## 화면 구성
- **맨 위 타임라인**: 시점 6개. 스토어 오픈일(D-0)만 정하면 날짜가 자동 계산되고, 오늘에 해당하는 시점에 '오늘' 표시.
- **왼쪽 상품 목록**: 등급(S·A·B·C·미정) + 순위. 끌어다 놓기 / ▲▼ / 등급 선택으로 정렬. 상품을 누르면 정보·링크 편집.
- **오른쪽**: 선택한 시점의 할 일 체크리스트와 원고.
- **하단 바**: 그 시점 원고 확정 개수와 전체 복사.

## 원고 규칙
- D-0 인스타·트위터 (상품별), D+14·D+30 인스타·트위터 (S·A 등급만), D-7 공지 1건.
- 트위터: `product-sns-formatter/rules/format-rules.js`의 메가하우스 예약시작 템플릿을 따름. 링크 자리에 스마트스토어 링크.
- 인스타: 링크 대신 "🛒 구매는 프로필 링크를 참고해주세요".
- D-7 공지 / D+14 / D+30 문구는 **규칙을 받기 전 임시 틀**. 규칙이 정해지면 `app.js`의 `gen()`만 고치면 된다.
- 원고를 직접 고치면 그 내용이 저장되고, "기본 틀로 다시"로 되돌릴 수 있다.

## 발주서 대조
- 엑셀 첫 번째 시트에서 '상품명/품명/제품명' 머리글 열을 자동으로 찾는다(못 찾으면 글자가 가장 많은 열). 미리보기에서 열을 바꿀 수 있다.
- 이름은 띄어쓰기·기호·"(재판)"을 빼고 비교하며, 한쪽이 다른 쪽을 포함해도 같은 상품으로 본다.
- 빠진 상품은 지우지 않고 줄을 그어 남기며 순위·원고에서만 뺀다. 한 줄도 못 읽으면 반영 버튼이 잠기고, 절반 이상 빠지면 경고한다.
- 엑셀 읽기는 `vendor/xlsx.full.min.js`(SheetJS 0.18.5)를 폴더 안에 두고 쓴다 — 회사망에서 외부 CDN이 막히거나 캐시돼도 동작하도록.

## 저장
- 브라우저 `localStorage`(`mhUploadBoard.v1`)에 회차별로 저장. 상단에 실제 저장 결과(저장됨 시각 / 저장 실패)를 표시.
- 다른 컴퓨터·팀원에게 넘길 땐 **백업 내려받기 → 백업 불러오기**(같은 회차는 덮어씀, 다른 회차는 유지).
- 같은 브라우저에서 탭을 두 개 열어도 서로 덮어쓰지 않고, 한 탭에서 바꾼 내용이 다른 탭에 바로 반영된다.
- 새 필드를 추가할 땐 `normProduct()` / `normRound()`에 기본값(`??`)을 같이 넣어 옛 저장본이 깨지지 않게 한다.

## 아직 안 된 것
- 번역기·캐러셀 바로가기 (주소를 몰라서 버튼 없음) → `app.js`의 `TOOL_URL`에 추가하면 버튼이 생긴다.
- 팀 공유 저장(서버). 지금은 개인 브라우저 저장 + 백업 파일.
