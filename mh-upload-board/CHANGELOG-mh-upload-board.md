# 2026-09-23 (V1.1 처음 온 사람도 헤매지 않는 화면)

### 화면 구성

- 오른쪽 맨 위에 '지금 할 일' 안내 한 줄 + 버튼 하나 — 시점과 진행 상황을 보고 다음에 누를 것을 알려줌
  (기술: nextAction()이 상품 유무·등급 미정·발주서 반영·링크·원고 확정·체크 상태 순으로 판단)
- 상품 목록은 평소엔 보기 전용(순위·이름·문제 표시만), 'D-7·D-1' 시점이나 '순위 편집'을 누를 때만 조작 버튼 표시
  (기술: editMode 상태, 시점 이동 시 EDIT_STAGES 기준으로 자동 전환)
- 할 일은 한 줄짜리 체크 칩으로 줄이고, 시점 제목·설명문은 타임라인과 안내로 대체
- 원고를 확정하면 다음 미확정 원고로 자동 이동
- 화면에 보이는 버튼 수: D-0 기준 134개 → 54개

# 2026-09-23 (V1.0 첫 버전)

### 회차 관리

- 스토어 오픈일만 정하면 D-7 ~ D+30 여섯 시점 날짜가 자동으로 잡히고, 오늘 시점에 '오늘' 표시
  (기술: 오픈일 기준 일수 차이로 현재 시점 계산, 회차별로 localStorage 저장)
- 새 회차 만들기, 지난 회차 다시 보기, 백업 파일 내려받기/불러오기
  (기술: 회차 객체를 JSON Blob으로 내보내고, 불러올 때 normRound로 빠진 필드 기본값 채움)

### 상품 목록

- D-7 리스트 붙여넣기(작품명 / 시리즈 / 상품명, 재판 표시) → 전부 '미정'으로 들어와서 인기도 정렬부터 시작
- 등급 S·A·B·C + 순위를 끌어다 놓기, ▲▼, 등급 선택으로 정리 — ▲▼는 등급 끝에서 누르면 옆 등급으로 넘어감
  (기술: HTML5 드래그앤드롭, 등급 순서를 유지하는 안정 정렬)
- 발주서 엑셀 대조: 새로 생긴 상품·빠진 상품을 미리 보여준 뒤 확인하면 반영, 한 줄도 못 읽으면 반영 잠금
  (기술: SheetJS를 폴더 안에 포함, 머리글 자동 탐지 + 열 수동 선택, 정규화한 이름으로 포함 비교)
- 스마트스토어 링크를 상품별로 넣거나 "상품명 + 링크" 목록으로 한꺼번에 채우기
- 마토메 메이커에 붙여넣을 작품명을 순위순 한 줄씩 복사

### 원고

- D-0·D+14·D+30 인스타/트위터 원고를 순위순으로 자동 생성, 직접 고치면 그 내용 유지, 확정 표시
- 트위터는 메가하우스 예약시작 규칙(140자, 링크 자리), 인스타는 링크 대신 "프로필 링크 참고" 문구
  (기술: 트위터 글자 수는 한글·이모지 2, 링크 23으로 세서 140자로 환산)
- 리마인드는 S·A 등급만 — 등급을 바꾸면 원고 개수가 따라 바뀜
- 발주서에서 빠진 상품을 이미 확정해 뒀으면 "올리지 마세요" 경고

### 안정성

- 탭 두 개로 열어도 서로 덮어쓰지 않고 다른 탭 변경을 바로 따라감
  (기술: 닫을 때는 대기 중인 저장만 실행, storage 이벤트로 재로드)

# 2026-09-28 (V1.2 실제 본사 리스트 형식 지원 + 마퀴 다중 선택)

### D-7 붙여넣기

- 실제 본사 프리뷰 리스트 형식("작품명 | 분류" 머리글 + 그 아래 "- 상품명" 여러 줄)을 지원
  (기술: 머리글 한 줄을 만나면 그 작품명·분류를 기억해두고, 뒤따르는 "-" 줄들을 전부 그 작품의
  상품으로 묶어서 읽는다 — 예전처럼 "-" 줄 하나하나를 별개 작품으로 잘못 잡던 문제 수정)
- 재판 표시로 "(재판)"과 "【재판】" 둘 다 인식
- 예전 "작품명 / 시리즈 / 상품명" 한 줄 형식도 그대로 지원(자동으로 구분해서 읽음)

### 순위 편집 — 마퀴(사각형 끌기) 다중 선택

- 이름 오른쪽 빈자리나 순위 번호 위에서 아래로 끌면 사각형으로 여러 상품을 한번에 고를 수 있음
- 고른 다음 화면 아래 뜨는 바에서 등급(S/A/B/C) 버튼 하나만 누르면 전부 그 등급으로 한번에 지정
  (하나하나 드롭다운을 눌러 등급을 정하던 번거로움을 줄임)
- "확보로 표시"로 여러 개를 한번에 확보 처리, Esc나 "선택 해제"로 고른 것 취소
- 손잡이(⋮⋮)를 잡고 끄는 건 그대로 "한 줄만 옮기기"로 남겨둠 — 마퀴와 섞이지 않게 구분
