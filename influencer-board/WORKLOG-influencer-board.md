### 새 주소에서 "아직 설정이 끝나지 않았습니다" / 키를 바꿔도 계속 401
- **문제** ▶ Vercel에 환경변수를 다 넣었는데 로그인 화면에 "설정이 끝나지 않았습니다"가 뜸. 값을 고쳐 재배포를 눌러도 변화가 없고 로그에는 `파일 조회 실패 (401)`이 남음
- **확인** ▶ 서버를 직접 호출해 보니 첫 배포는 값이 없는 채로 만들어져 있었음(`503`). 푸시로 새 배포를 만들자 `401`(코드 틀림)로 바뀌어 값은 들어감. 그 뒤 키를 바꾸고 누른 Redeploy는 `Ignored Build Step … exit code 0`으로 **전부 취소**되고 있었음 — "폴더가 안 바뀌었으면 배포 취소" 설정 때문. 가이드 프로젝트 문서에 같은 함정이 적혀 있었는데 인플 보드엔 적용하지 않았고, 그래서 키를 바꿨는데도 옛 키로 계속 401이 났음
- **처리** ▶ 이 폴더의 문서를 고쳐 푸시해 새 배포를 일으킴. 계획서에 "Redeploy 버튼은 안 먹히니 파일을 바꿔 푸시한다"는 방법과 확인 방법(503→401)을 적어 둠

### 노션 표를 붙여넣으면 활동명이 아이콘 글자로 읽힐 뻔한 문제
- **문제** ▶ 담당자가 실제 노션 표(맨 앞 칸 `:ins:` 아이콘, 이름 칸은 "활동명 (계정아이디)")를 보내줌. 만들어 둔 붙여넣기는 첫 칸을 활동명으로 읽어 `:ins:`가 활동명이 됨
- **확인** ▶ 샘플 없이 "주소가 아닌 첫 칸 = 활동명"이라고 가정해 만든 규칙이라, 실제 표의 첫 칸이 아이콘이라는 걸 몰랐음
- **처리** ▶ 머리글의 '이름' 칸을 찾아 쓰고, 괄호 앞까지만 활동명으로 취하게 수정. 머리글이 없을 때는 아이콘·주소 칸을 건너뜀
- **결과** ▶ 실제 표 6줄을 마크다운·탭 두 모양으로 붙여 모두 6명을 정확히 읽음(바보개구리·봉이·또유네·커비·냐·닝머)

### 전체 점검에서 나온 문제 — CSV 수식 실행
- **문제** ▶ 쿠폰 CSV에 크리에이터가 직접 쓴 희망 상품이 그대로 들어감. `=`나 `@`로 시작하면 엑셀이 열자마자 수식으로 실행할 수 있음
- **확인** ▶ 시험 데이터로 `=HYPERLINK(...)`를 넣어 CSV에 그대로 나오는 것을 확인. 만들 때는 "표로 보여주는 것"만 생각하고 "엑셀로 열린다"는 점을 놓침
- **처리** ▶ 표 복사·CSV 모두 위험한 문자로 시작하는 칸 앞에 `'`를 붙여 글자로만 읽히게 함. 확정 후보 링크도 화면에서 `http(s)`만 열리게 한 겹 더 막음
- **결과** ▶ 같은 시험에서 위험한 칸 0개. 화면에 끼워넣기 공격(이름·링크에 스크립트 입력)도 실행되지 않음을 확인
