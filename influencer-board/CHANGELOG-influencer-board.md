# 2026-10-14 (V1.0 담당자 화면 분리와 응대 기능)

### 분리
- 크리에이터 가이드 안에 있던 담당자(관리자) 화면을 별도 도구로 분리
  (기술: `reward-view-admin.html` + `api/admin.js` + `lib/github.js`를 복사해 독립 Vercel 프로젝트로 구성, 데이터는 기존과 같은 비공개 저장소 `creator-logs/*`를 그대로 읽고 씀)
- 기존 기능은 그대로 — 접수 목록, 업로드 확인, 리워드 지급 표시, 수령 방식 변경, 오픈 날짜 관리
- 배포되는 파일은 화면 파일과 robots.txt뿐 — 계획서 같은 내부 문서는 주소로 열리지 않음
  (기술: `vercel.json`의 buildCommand가 `dist/`에 두 파일만 복사)

### 회차 현황 (새 입력 없음)
- 회차별 주간 할 일 표 — 초안·업로드 확인·1차 지급·정산이 몇 건인지 주마다 표시
- 두 회차 이상의 일이 같은 주에 몰리면 "겹침"으로 표시, 날짜가 지났는데 안 끝난 일은 "밀린 일"에 모음
- 크리에이터별 현재 단계와 다음 날짜 표시
  (기술: 초안일·오픈일·업로드 확인·지급 표시만으로 계산, 오픈일은 가장 가까운 오픈일 기준)

### 쿠폰 발급
- 지급할 차례가 된 건의 네이버 ID·차수·금액(또는 상품)·지급 예정일을 한 표로 표시
- 표 복사와 CSV 내려받기, 발급 후 지급 표시 버튼 (접수 목록과 같은 값이라 양쪽에 반영)
- 2차(750↑ 여부)와 후지급(정산 결과) 금액은 "확인 필요"만 표시, CSV에는 조건 설명 없이 값만 포함
- 크리에이터가 쓴 글이 엑셀에서 수식으로 실행되지 않도록 방어
  (기술: `=`, `+`, `-`, `@`로 시작하는 칸 앞에 `'` 부착 — CSV 수식 주입 방어)
- 좁은 화면(폰)에서는 건마다 카드로 표시

### 확정 후보
- 노션에서 최종 확정된 분의 표를 복사해 붙여넣으면 활동명·링크를 읽어 목록에 추가
- 접수 목록과 활동명이 같으면 자동으로 이어져 "접수 전 / 접수됨 · 현재 단계" 표시
- 연락 이력 칸은 자리만 있음 (메일 추출 파일 반영 예정)
  (기술: 비공개 저장소 `creator-logs/candidates.json` 신규 파일, 기존 파일은 변경 없음 — 없으면 빈 목록으로 처리)
