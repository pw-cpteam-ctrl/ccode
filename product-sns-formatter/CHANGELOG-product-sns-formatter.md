## 2026-08-20 (V2.4 브랜드별 캐러셀 틀 + 사전 저장 구조 개선 + UI 리뉴얼 시안)

### 브랜드별 캐러셀 틀 (신규 기능)
- **부시로드 상품은 초록 틀로, 굿스마일·메가하우스는 기존 주황 틀로 출력**
  (기술: `FRAMES` 테이블에 브랜드별 틀 그림과 투명 창 좌표를 함께 보관, `frameOf(p)`가 상품
  브랜드로 선택)
- **틀마다 다른 투명 창 크기를 실측해 사진·그라데이션·글자·배지 위치를 그 틀 기준으로 계산**
  (기술: 알파 채널 픽셀 스캔으로 창 좌표 산출(주황 y0 117 / 초록 y0 112),
  `drawSlide`·`fitRectFor`·`clampSlideOffset`이 틀을 인자로 받게 변경)
- **전용 틀이 없는 브랜드는 기본 틀로 자동 대체** — 브랜드가 늘어도 틀 없이 나가지 않음
  (기술: `frameKeyFor`가 미등록 브랜드를 `goodsmile`로 폴백)
- **상세 화면에서 브랜드를 바꾸면 틀이 즉시 교체됨**
  (기술: 브랜드 변경 시 새 틀 로드 후 `clampSlideOffset` 재적용 + 캐러셀 재렌더)
- **화면에 한 번도 안 띄운 상품을 내보낼 때도 틀이 빠지지 않게 처리**
  (기술: `exportSlidePng`이 그리기 전에 해당 브랜드 틀 로딩을 대기)

### UI 리뉴얼 시안 (코드 미반영)
- **1920×1080 기준으로 화면을 재고 현재 / A안 / B안 비교 목업을 만듦** — 실제 도구 코드는 그대로
  (기술: 도구의 색·폰트 토큰을 그대로 쓴 단일 HTML 목업, 1920px 캔버스를 축소 표시,
  [비교 시안](https://claude.ai/code/artifact/fa5df6d0-4d18-46bf-b680-64b5e452950b))
- **A안(정보 정리 위주)으로 진행 결정** — 안내 접기(접은 상태 기억), 목록 자체 스크롤,
  내려받기·복사를 하단 고정 바로, 원고 옆 캐러셀 글자 미리보기, 한 줄에 하나씩 쌓인 컨트롤 붙여 앉히기
  (기술: 목업 측정값 문서 높이 5503 → 2504px, 오른쪽 빈칸·내려받기 스크롤 0,
  혼자 한 줄 쓰는 칸 4개 → 0개)
- **배치와 섞지 말고 먼저 고칠 버그 1건 확인** — 사진 삭제(✕)만 확인창이 없어 누르는 즉시 지워짐
  (기술: 상품 삭제·상품 초기화·원고 재생성은 `confirm` 있음, `th-del` 핸들러만 없음)

### 저장·배포 구조 개선
- **작품명 정식표기를 저장해도 페이지 재배포가 돌지 않게 변경** — 저장 즉시 팀원 화면에 반영
  (기술: `api/work-titles.js`가 GitHub Contents API로 사전을 직접 읽어 반환,
  `vercel.json` 배포 판단 대상에서 `data/work-titles.json` 제외)
- **서버 함수를 못 쓰는 상황에서도 사전이 비지 않게 처리**
  (기술: 404·502·환경변수 미설정 시 기존 배포 파일 `./data/work-titles.json`로 폴백)

## 2026-08-19 (V2.3 부시로드 ZIP 가져오기 + 작품명 정식표기 사전)

### 캐러셀 글자
- **캐러셀 하단 흰 글자를 프리젠테이션(Freesentation) 폰트로 변경** — 제목 800(엑스트라볼드),
  부제 700(볼드)
  (기술: 구글폰트 미제공이라 눈누 배포 주소를 `@font-face`로 연결, 사용하는 두 굵기만 로드,
  `ensureCanvasFont`로 그리기 전 로딩 대기 + 4초 초과 시 시스템 폰트 폴백)

### 부시로드 메일 ZIP 가져오기 (신규 기능)
- **메일로 받은 ZIP을 압축 풀지 않고 그대로 올리면 사진이 들어옴** — 여러 개 동시 가능
  (기술: 기존 JSZip으로 읽기, 파일명이 Shift_JIS인 경우 직접 디코딩해 한글 환경 깨짐 방지)
- **발주서 엑셀이 같이 있으면 상품과 스펙까지 자동 생성** — 없으면 상품 1개에 사진을 모두 담음
  (기술: .xlsx가 압축 파일인 점을 이용해 라이브러리 추가 없이 표 파싱, 열 위치 대신 라벨
  글자로 값 탐색)
- **사진과 상품 연결을 자동으로 확정하지 않고 후보만 제시** — 못 고른 사진은 첫 상품에 넣고 안내
  (기술: 파일명 일본식 약어 매칭, 전체 세트컷(fullset)은 의도적으로 미배정)
- **가져오기 입구를 브랜드별로 하나만 표시**
  (기술: `syncImportZones`가 브랜드 라디오 변경 시 입구 표시 전환)

### 작품명 정식표기 (신규 기능)
- **한 번 확인한 작품의 한국 정식 제목을 저장해 다음부터 자동 적용** — 같은 작품의 다른
  상품에도 즉시 반영
  (기술: 영문·일문 어느 쪽으로도 조회되는 사전, `lookupWorkTitle`·`saveWorkTitle`)
- **저장된 표기가 없으면 "확인 필요"를 상품 목록·진행 표시·상세 3곳에 표시** — 지어낸 표기가
  그대로 원고로 나가는 것을 차단
  (기술: `workBlockHtml` 확정/미확정 분기, `needsWork` 플래그로 3개 화면 동시 표시)
- **원문을 일본어·영어로 전환해서 볼 수 있고, 검색어는 일본어 원제로 넣음**
  (기술: `workLocale` localStorage 저장, `workSearchUrl`)
- **표기를 팀 전체가 공유** — 서버 저장이 실패해도 이 브라우저에는 남고 실패 사실을 알림
  (기술: `api/save-work-title.js`가 `data/work-titles.json`에 커밋)
- **AI가 작품명을 지어내지 않게 규칙 강화** — 확정 표기가 있으면 강제, 없으면 팀이 써온 표기
  74개 중에서 고르게 함
  (기술: `/api/format` 요청에 `workKo`·`workCandidates` 전달)

### 버그 수정
- **캐러셀 이미지 단이 화면에서 사라진 자리에 그려서 내용이 안 보이고 오류가 나던 문제 수정**
  (기술: `renderImageStage`가 대기 후 `#stage3`를 다시 조회하고, 그 사이 활성 상품이 바뀌었으면
  렌더링을 건너뜀)

## 2026-07-31 (V2.2 지어낸 수식어 차단 + 전체점검 버그 수정)

### 원고 규칙
- **상품정보에 없는 감성적 수식어·묘사를 AI가 지어내지 못하게 차단** — "깜찍하게", "사랑스러운"
  같은 표현은 원문에 근거가 있을 때만 사용, 재료가 없으면 짧게 끝내도록 변경
  (기술: `api/format.js`의 `buildPrompt`에 수식어 금지 항목 + 결과 자체점검 지시 추가, 브랜드 3종 공통 적용)

  경우에 동일 적용, 이 예시에만 매몰되지 말 것"을 규칙에 포함
  (기술: 프롬프트 규칙 문구 내 일반화 조항 명시)

### 캐러셀 부제 (버그 수정)
- **사람이 손으로 고친 부제가 검수·재생성 때 덮어써져 사라지던 문제 수정** — 칸을 비우면 다시
  자동 채움으로 복귀
  (기술: `textSubManual` 플래그로 자동 채움 차단, `autoFillProductLineSub`에서 분기)
- **참고할 상품 원문이 없는데도 부제에 "스케일 피규어"가 강제로 붙던 문제 수정** — 실제 스펙
  정보가 있는 상품에만 기본값 적용, 매칭 대상을 제목·메모까지 확대
  (기술: `matchProductLine`에 `allowScaleFallback` 옵션 추가)

### 일괄 원고 생성 (안정성)
- **일괄 생성 중 "상품 초기화"가 눌려 남은 AI 호출이 헛돌던 문제 수정** — 진행 중에는 초기화 차단
  및 버튼 잠금
  (기술: `batchRunning` 가드 + `#btnResetProducts` disabled 처리)
- **일괄 생성이 예외로 죽으면 잠금이 안 풀려 초기화가 영구 차단될 수 있던 문제 수정**
  (기술: `try`/`finally`로 잠금 해제 보장, 화면 갱신 실패를 배치 루프와 격리)

### B2B 가져오기
- **결과 폴더 안내문구를 "오늘 날짜" → "발표일 날짜"로 수정** — 저녁에 스크랩하면 다음날 날짜
  폴더가 생기는 것을 안내에 반영
  (기술: `#b2bImportStatus` 문구 수정)

    파일(JSON+사진)을 선택하면 상품 목록에 자동 반영

    로그인 진행 후 이어서 완성 예정)
