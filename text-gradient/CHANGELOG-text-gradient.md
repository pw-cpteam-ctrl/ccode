## 2026-08-05 (V2.8 ~ V3.2 폴더 단위 작업 · 대표 사진 · 아트보드 삭제)

### 폴더 단위 작업 (신규 기능)
- 폴더를 통째로 올리면 사진이 뒤섞이던 문제 해결, 같은 폴더 사진이 항상 붙어서 들어옴
  (기술: `webkitRelativePath`로 하위폴더명 추출(`folderOfFile`) 후 폴더→파일명 2단 정렬 — 기존엔 경로를 버리고 파일명만으로 정렬)
- 폴더마다 색을 배정해 미리보기 칸 이름표와 매칭표 색칩으로 구분 표시 (폴더 2개 이상일 때만)
  (기술: `folderColorMap`에 등장 순서대로 색 배정, `rebuildFolderColors`를 렌더 시 호출)
- **사진 하나를 클릭하면 그 폴더 전체가 한 단위로 선택**돼서 폴더 단위 일괄 작업 가능
  (기술: `selectFolderGroup` — 매칭표 사진/파일명 칸과 미리보기 폴더 이름표 양쪽에서 동작)
- 폴더명과 투명파일명을 비교해 자동 배정하는 기능 추가 (외부 AI·서버 없이 글자 비교만)
  (기술: 확장자·공통 꼬리표(제목/타이틀/title)·구분기호 제거 후 완전일치 1.0, 부분포함 0.95, 그 외 2-gram Dice 계수. 0.5 미만 또는 1·2등 차 0.08 미만은 "애매함"으로 건너뜀)
- 자동 배정 전에 어느 폴더에 무엇이 몇 %로 들어가는지·왜 건너뛰는지 먼저 보여주고 확인받음
  (기술: `buildFolderMatchPlan`으로 계획만 세운 뒤 confirm, 이미 배정된 사진은 미변경)

### 대표 사진(★) (신규 기능)
- 폴더(상품)마다 대표 1장을 지정해서 **표지에만 제목·뱃지가 들어가게** 함
  (기술: 사진에 `isMain` 표시 — 인덱스로 기억하면 순서 변경 시 엉뚱한 사진으로 옮겨가므로. `normalizeMains`가 렌더마다 "폴더당 정확히 1장" 규칙 복구)
- "대표만 남기고 나머지 투명 제목 빼기" 버튼 + 되돌리기 추가
  (기술: 투명 배정을 지우지 않고 `noFrame` 플래그로 그리기만 생략 — 되돌리기 가능하고 작업 유실 없음)
- 뱃지·스토어명이 스토어명을 채운 모든 사진에 나오던 것을 대표 1장에만 나오도록 변경
  (기술: `drawBadge` 진입 조건을 `!it.storeName`에서 `!it.isMain`으로 교체)
- 스토어명 글자색을 검정/흰색 중에 고르는 버튼 추가
  (기술: 전역 `storeTextColor` + localStorage 저장, 후광(glow)을 글자색 반대색으로 자동 전환 — 흰 글자에 흰 후광이면 대비가 사라짐)

### 아트보드 삭제·되돌리기 (신규 기능)
- 개별 삭제가 없어 "새로 시작(캐시 지우기)"로 전부 날리는 수밖에 없던 문제 해결
  (기술: 칸마다 ✕ 버튼 + 선택바 "선택 삭제", 2장 이상은 confirm)
- 지운 사진을 원래 자리 그대로 되살리는 되돌리기 추가
  (기술: `deleteItems`가 삭제 항목의 원래 인덱스를 기억해 오름차순 재삽입, 사진 데이터는 메모리에 유지)
- 대표를 지우면 같은 폴더의 이웃(뒤쪽 우선)이 대표를 이어받음
- 되돌리기 버튼을 기능별로 나누지 않고 하나로 통합, 무엇을 되돌리는지 버튼에 표시
  (기술: `setUndo(label, fn)` / `clearUndo()`, 사진 목록이 바뀌면 낡은 되돌리기 자동 폐기)

### 투명 이미지 배정 방식 개편
- 파일명이 뜻 없는 문자열이라 식별이 안 되던 문제 — **사진을 보면서 고르도록** 칸 아래 드롭다운 추가
  (기술: 처음엔 썸네일 팔레트 팝오버로 만들었다가 조작 영역이 좁아 `.ovSel` 드롭다운으로 교체, 미배정 칸은 빨갛게 표시)
- 매칭표 왼쪽에 작은 사진 썸네일 칸 추가 — 드래그 채우기로 대량 배정할 때도 사진 보고 판단 가능
  (기술: 그리드 썸네일용 저해상도 캐시(`getThumbSourceCanvas`) 재사용)
- 투명을 고르면 "적용" 버튼 없이 즉시 합성되도록 변경
  (기술: 배정 로직을 목록 단위 `assignOverlayMany` 하나로 통합 — 칸 드롭다운/표 드롭다운/드래그 채우기 모두 같은 경로, 이미지는 1회만 로드)
- 드롭다운 항목을 미리 만들지 않고 펼칠 때 채우도록 처리
  (기술: 사진 수백 장 × 후보 수십 개 = 수천 `<option>` 방지, `overlayPoolVersion`으로 후보 변경 감지)

### 복수선택 (신규 기능)
- 칸마다 선택 체크박스 + Shift+클릭 범위 선택, 선택 시 상단 고정 바에 일괄 작업 버튼 표시
- **마우스로 끌어서 사각형으로 쓸어 담는 선택** 추가 (Ctrl+드래그로 기존 선택에 더하기)
  (기술: 미리보기 패널 전체에 마우스 이벤트 위임 + 페이지 좌표 기준 교차 판정, 드래그 중 화면 끝 자동 스크롤, 5px 이내 이동은 클릭으로 취급해 기존 편집기 열기 유지)
- "전체 선택" / "투명 미배정만 선택" 버튼 추가
- 선택된 칸에서 휠·드래그하면 선택한 전부가 같이 확대/축소·이동
  (기술: 최소 배율은 사진 비율마다 달라 칸별로 따로 계산, 조작 중엔 화면에 보이는 칸만 갱신하고 화면 밖은 손 뗀 뒤 일괄 갱신)

### 사진 위치·크기 조정
- 미리보기 칸에서 팝업 없이 바로 사진을 끌어 위치 조정 가능
  (기술: `mousemove`/`mouseup`을 window에 1벌만 등록하고 대상은 `_panDrag`에 보관, 화면 이동거리를 원본 좌표로 환산 — 환산 없으면 축소 배율만큼 느리게 움직임)
- **사진을 아트보드 밖으로 밀어낼 수 있던 버그 수정** (그 상태로 저장하면 배경색만 남은 이미지가 나왔음)
  (기술: 위치를 픽셀 오프셋(`ox`/`oy`)에서 정규화 좌표(`focusX`/`focusY`, 0~1)로 교체해 범위 초과가 원천 불가능하게 함)
- 아트보드보다 가로로 넓은 사진은 처음부터 전체가 보이는 크기로 시작 (새로 불러오는 사진만 적용)
  (기술: `defaultZoom`/`containMinZoom`, Shift+휠로 그 크기까지 수동 축소도 허용)
- 꽉 채울 때 반올림 오차로 배경이 실선처럼 비치던 것 방지
  (기술: cover-fit 배율에 여유값 `SLOP=1.003` 적용)
- 기존 조정값 보존 처리
  (기술: 불러올 때 옛 방식→새 방식 변환(`migrateGeom`), 새 값에서 옛 필드를 역산해 함께 저장(`legacyGeomOf`)해 되돌림 안전장치 유지)

### 다운로드
- ZIP이 전부 한 곳에 쏟아지고 폴더마다 같은 파일명이면 번호만 붙어 구분 불가하던 문제 해결
  (기술: `폴더명/01_원본파일명.png` 형태로 하위폴더 생성, 대표(★)를 01로 앞당겨 배치 — 인스타 첫 장이 표지로 들어감)
- 개별 다운로드 파일명에도 폴더명을 붙여 같은 파일명 구분 가능하게 함

### 성능 개선
- 미리보기 크기 슬라이더가 300장에서 한 틱에 3초씩 멈추던 문제 해결
  (기술: 끄는 동안엔 기존 캔버스를 CSS로만 확대/축소하고, 손 뗀 뒤 디바운스로 `resizeThumbsSharp` 1회 — 칸 DOM 재생성 제거. 9틱 합계 약 27초 → 6.5ms)
- 성능 때문에 껐던 뱃지 그림자를 썸네일에서도 다시 켬
  (기술: 그림자만 오프스크린에 1회 그려 이미지로 캐싱(`getBadgeShadowSprite`, `destination-out`으로 몸통 제거) 후 `drawImage`로 붙여넣기 — 300장 렌더 시간 차이 없음)

### 버그 수정
- "사진 폴더 선택(기존 리스트 비우고 새로)"이 교체되지 않던 문제 (원인 3건)
  (기술: ① 선택창 열기 전 `input.value` 미초기화로 같은 폴더 재선택 시 change 미발생 ② `loadImage` 실패 시 예외로 교체·렌더 코드가 아예 미실행 → 파일별 try/catch로 건너뛰고 로그 표시 ③ `type`이 빈 파일이 전부 필터링 → 확장자 기준 보조 판정 추가)
- 이미 정리된 폴더에서 대표를 바꾸면 예전 대표에도 제목이 남아 한 폴더에 제목이 2개가 되던 문제
- 사진 목록이 바뀐 뒤에도 낡은 "되돌리기"가 남아 엉뚱한 사진에 적용될 수 있던 문제
- "새로 시작"이 선택 상태·폴더 색 배정을 초기화하지 않아 다음 작업에 섞일 수 있던 문제
- 폴더 이름표에서 드래그를 시작하면 폴더 선택과 사각형 선택이 겹쳐 발동하던 문제
- 어두운 뱃지 색을 고르면 검은 글자가 안 보이던 문제
  (기술: 배경 밝기 계산으로 글자색 자동 전환(`readableTextColor`))
- 투명 선택 버튼 라벨이 이모지 폰트 없는 환경에서 빈 사각형으로 보이던 문제 (글자 라벨로 교체)

### 뱃지 색상
- 코드에 고정돼 있던 뱃지 색을 도구 안에서 직접 고르게 함
  (기술: 미리보기 툴바에 색상 입력칸 추가, 월·글자굵기와 함께 localStorage 저장)

## 2026-08-03 (V2.7 월 리본 뱃지 + 스토어명 레이어)

### 3번째 합성 레이어 (신규 기능)
- 사진·투명 이미지 위에 "월 리본 뱃지 + 스토어명"을 코드로 직접 그리는 레이어 추가
  (기술: `drawBadge` — 이미지가 아니라 Canvas 2D로 그려서 월 숫자·스토어명이 자유롭게 바뀜, S-Core Dream 웹폰트 사용)
- 매칭표를 2칸에서 3칸으로 확장해 스토어명을 사진별로 입력·드래그 채우기 가능하게 함
  (기술: 채우기 손잡이 로직을 `data-field` 기준으로 일반화(`makeFillableCell`))
- 뱃지·스토어명 좌우 위치를 칸마다 전환하는 버튼 추가
- 스토어명 글자와 로고에 공통 흰 후광을 적용해 사진 위에서도 읽히게 함
  (기술: 딱딱한 테두리(`strokeText`) 대신 `shadowBlur` 기반 soft glow를 텍스트·로고 양쪽에 동일 적용)

### 성능 개선
- 사진 300장 기준으로 클릭할 때마다 심하게 렉 걸리던 문제 해결
  (기술: 원본 고해상도를 매번 리샘플링하던 것을 최초 1회 저해상도 캔버스로 캐싱(`getThumbSourceCanvas`, 최대 480px), 비용 큰 `shadowBlur`는 썸네일에서 생략 — 12~13초 → 0.3~0.8초)

### UI 정리
- 파일명이 길면 썸네일 칸이 밀려 보이던 문제를 말줄임표 처리로 수정
- 기존 리스트를 유지하고 폴더를 뒤에 이어붙이는 "폴더 추가" 버튼 추가
- 매칭표 입력칸 여백 확보

## 2026-07-23 (V2.2 ~ V2.6 사진 일괄 합성 도구(batch-merge) 신규 추가)

### 사진 일괄 합성 도구 (신규 기능)
- 엑셀/CSV 매칭표 + 사진 + 투명 이미지를 올리면 1080×1350 캔버스에 자동 합성하는 도구 추가
  (기술: `text-gradient/batch-merge.html` 신규 파일, Canvas 2D `drawImage` 기반 합성 — 라이브 텍스트가 없어 html-to-image 미사용)
- 사진 비율이 제각각이어도 꽉 채워 중앙 자르기(cover-fit) 기본 적용, 필요한 사진만 확대/축소·드래그로 수동 조정 가능
  (기술: cover-fit 배율 계산 후 `scaleMul`/`ox`/`oy`로 오프셋 적용, 축소로 여백 생기면 배경색으로 채움)
- 배경색을 흰색 또는 사진에서 뽑은 주요색으로 자동 지정하는 기능 추가
  (기술: 24×24 축소 캔버스 픽셀 평균값으로 대표색 추출)
- 결과 전체를 zip 파일 하나로 일괄 다운로드하는 기능 추가
  (기술: JSZip, 파일명 중복 시 순번 접미사 자동 부여, 진행률 표시)

### 저장 안정성
- 새로고침해도 작업 중이던 조정 내용이 그대로 복원되도록 개선
  (기술: IndexedDB에 원본 파일은 매칭 직후 1회만 저장하고 줌/위치/배경색 조정값은 400ms 디바운스로 저장 분리, localStorage는 조정값 백업 폴백으로만 사용)
- 아직 사진에 배정되지 않은 투명 이미지 후보까지 새로고침 후 유지되도록 수정
  (기술: 오버레이 파일 풀을 별도 캐시 키(`overlay_pool`)로 분리 저장 — 기존엔 이미 배정된 것만 복원되던 구멍 수정)

### 입력 편의성 (신규 기능)
- 엑셀 첫 줄이 헤더여도 자동으로 인식해서 건너뛰는 기능 추가
  (기술: 첫 줄이 업로드 파일과 매칭 안 되고 확장자 형태도 아니면 헤더로 판단해 자동 스킵)
- 사진 폴더를 통째로 선택하면 엑셀 없이 바로 아트보드+리스트가 만들어지는 기능 추가
