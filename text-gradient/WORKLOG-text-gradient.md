## 2026-08-03

### 사진 일괄 합성 도구(batch-merge)에 "월 리본 뱃지 + 스토어명" 레이어 추가
- **무슨 문제/요청이 있었나**: 사진+투명 오버레이 2단 합성만 되던 도구에, "이번 달 신제품" 리본 뱃지와 스토어명 문구를 사진마다 다르게 넣고 싶다는 요청. 이미지 파일이 아니라 입력값에 따라 매번 새로 그려지는 텍스트/도형이어야 함
- **어떻게 처리했나**: 매칭표를 2열(사진파일명/투명파일명)에서 3열(스토어명 추가)로 확장하고 기존 드래그채우기(채우기 손잡이) 로직을 그대로 재사용. S-Core Dream 무료 웹폰트를 CDN으로 적용하고 글자 굵기(100~900) 드롭다운 추가. 리본 뱃지·스토어명 전부 Canvas 2D로 코드로 직접 그려서(`drawBadge` 함수), 값이 바뀌면 미리보기/ZIP 내보내기에 자동 반영되게 함. 뱃지 좌우 위치를 사진별로 바꾸는 토글 버튼(⇄)도 썸네일에 추가
- **결과**: Playwright로 3열 표시·드래그채우기·뱃지 렌더링·좌우토글·새로고침 후 캐시 복원까지 직접 조작해서 확인함

### 스토어명 글씨가 안 보이고, 크게보기 창엔 뱃지가 아예 안 보이는 문제
- **무슨 문제/요청이 있었나**: 뱃지는 나오는데 스토어명이 흰 글씨+검은 그림자라 사진 위에서 안 보임. 썸네일 클릭해서 위치/배율 조정하는 창(에디터)에는 뱃지가 아예 안 보임
- **확인해보니**: 에디터 창은 사진+오버레이를 `<img>` 태그로 겹쳐 보여주는 DOM 방식이라, 캔버스에만 그리는 뱃지가 반영될 자리가 없었음
- **어떻게 처리했나**: 스토어명을 검은 글씨+흰 테두리로 변경. 에디터 안에 뱃지 전용 캔버스 레이어(`#editBadge`)를 추가해서 실제 렌더링과 동일하게 미리 보이게 함
- **결과**: Playwright로 에디터 캔버스에 뱃지가 그려지는 것 확인

### 뱃지 모양이 레퍼런스 이미지랑 다르게 나오는 문제 (여러 차례 수정)
- **무슨 문제/요청이 있었나**: 리본 뱃지 모양이 이상하다는 신고가 반복됨. 이 과정에서 레퍼런스 이미지가 대화 중간에 컨텍스트에서 사라져 안 보이는 상태로 계속 추측해서 고치다가 여러 번 어긋남 (사용자를 상당히 답답하게 만든 부분 — 안 보이면 바로 말했어야 했는데 뒤늦게 인지함)
- **확인해보니**: 처음엔 리본 아래쪽이 바깥으로 뾰족하게 튀어나오는 모양(V자, 다리가 아니라 중앙이 돌출)으로 만들었는데, 실제 요청은 정반대 — 좌우 모서리가 다리처럼 길게 내려가고 가운데만 위로 파인 모양(A자)이었음. 크기도 240px 높이가 필요한데 훨씬 작게(112px) 만들어 짜부러져 보였고, 폭도 450px로 너무 넓적해서 레퍼런스(정사각형에 가까운 비율)와 안 맞았음
- **어떻게 처리했나**: 다각형 좌표를 반대로 뒤집어 다리+중앙노치 모양으로 재작성(`roundedPolyPath` 헬퍼로 모서리 둥글기 지정 가능하게 구현). 높이 240px 기준으로 비율 유지한 채 스케일업, 이후 실측 비율(260×240 → 최종 183×240)로 재조정, 노치 깊이도 절반으로 축소
- **결과**: 매 수정마다 Playwright로 1080×1350 원본 해상도로 직접 렌더링한 스크린샷을 찍어 실제 형태를 확인한 뒤에만 반영함

### 뱃지 최종 수치를 임시 조정 도구로 확정
- **무슨 문제/요청이 있었나**: "초기에만 슬라이더로 실시간 조정해보고, 한번 정해지면 그 값이 코드에 고정돼서 팀원용 화면엔 슬라이더가 안 남았으면 좋겠다"는 요청
- **어떻게 처리했나**: 위치/크기/글자크기를 슬라이더로 조정하고 "값 복사" 버튼으로 수치를 뽑아낼 수 있는 임시 페이지(`text-gradient/badge-tuner.html`)를 만들어 잠깐 배포. 확정된 값(`bw=183, bh=240, notch=45, radius=0, offsetX=77` 등)을 `drawBadge`에 그대로 하드코딩한 뒤 조정 도구는 삭제. 스토어명도 뱃지와 동일하게 top 정렬로 바꾸고, 스토어명 왼쪽에 PW 로고(`assets/favicon-pw.png`)를 폰트 높이에 맞춰 축소해 추가 — 로고+텍스트를 한 덩어리로 계산해서 뱃지가 좌/우 어느 쪽에 있어도 로고가 캔버스 밖으로 안 나가게 처리
- **결과**: 확정 렌더링 결과를 스크린샷으로 직접 만들어 확인. 조정 도구는 삭제 후에도 git 기록에 남아있어, 나중에 사용자가 다시 요청했을 때 `git show`로 복구해서 파일로 전달함

### 월 표기 방식 + 로고 크기/정렬 다듬기
- **무슨 문제/요청이 있었나**: "07"처럼 0 채운 2자리 대신 "7월" 형식으로, 로고는 기존 크기의 200%로 키워서 상하좌우 정중앙 정렬로 바꿔달라는 요청. 이어서 로고에 이미 "PW"가 들어있으니 텍스트 쪽 "PW 메가하우스 공식스토어"에서 "PW"를 빼고 "메가하우스 공식 스토어"로, 로고와 텍스트 수평이 미묘하게 안 맞는 것도 3px 위로 보정해달라는 요청
- **어떻게 처리했나**: `padStart(2,'0')` 제거하고 `${badgeMonth}월` 형식으로 변경. 로고 높이를 스토어명 폰트 크기의 2배로 키우고 텍스트 세로 중앙에 정확히 맞춰 정렬. 입력 예시 문구에서 "PW" 제거, 로고 Y좌표에 `-3` 보정 추가
- **결과**: 매 단계 Playwright 렌더링 스크린샷을 채팅으로 직접 보내 확인받은 뒤 반영

### 리본 뱃지에 그림자 추가
- **무슨 문제/요청이 있었나**: 노란 리본 뱃지에 4시 방향으로 흐리게 퍼지는 그림자를 넣어달라는 요청
- **어떻게 처리했나**: 뱃지 도형을 채우기 직전에만 `shadowColor`/`shadowBlur`/`shadowOffsetX`/`shadowOffsetY`를 설정해 그림자를 적용하고, 글자에는 안 묻도록 채우기 직후 그림자 설정을 초기화

### 썸네일이 300장 기준으로 클릭할 때마다 심하게 렉 걸리는 문제
- **무슨 문제/요청이 있었나**: "300개 캐시 담아서 그런지 클릭 한 번 할 때마다 엄청 렉 걸리고, 이보다 사양 낮은 PC는 아예 못 쓸 수준"이라는 신고. 썸네일 화질을 낮추고 클릭해서 크게보기만 원본 화질로 보여주는 방법을 제안받음
- **확인해보니**: 두 가지 원인이 겹쳐 있었음 — ① 썸네일 300개가 매번 원본 고해상도 사진을 직접 리샘플링해서 그리고 있었음 ② 방금 추가한 뱃지 그림자(`shadowBlur`)가 캔버스에서 원래 비용이 큰 연산인데 썸네일 300개 전부에 그대로 적용되고 있었음 (그림자 추가할 때 미리 못 걸러낸 부분)
- **어떻게 처리했나**: 사진마다 최초 1회만 축소 캔버스(최대 변 480px)를 만들어 캐싱(`getThumbSourceCanvas`)하고, 그리드 썸네일은 항상 이 축소본에서만 그리는 전용 함수(`drawItemThumb`)를 분리. 썸네일에서는 뱃지 그림자를 생략(`drawBadge(ctx, it, {shadow:false})`)하고, 클릭해서 크게보기·실제 PNG 다운로드·ZIP 내보내기는 기존처럼 원본 화질+그림자 그대로 유지
- **결과**: 수정 전/후를 실제로 300장 합성 상태로 만들어 직접 측정 — 뱃지 켜진 상태에서 설정 하나 바꿔 다시 그리는 시간이 12~13초 → 0.3~0.8초로 줄어듦 (git stash로 수정 전 코드를 잠깐 복원해 같은 조건으로 대조 측정함)

### 파일명이 길면 썸네일 칸이 밀려 보이는 문제 + 초기화/추가 방법 문의
- **무슨 문제/요청이 있었나**: 사진 파일명이 길면 썸네일 아래 파일명을 다 보여주느라 칸 정렬이 밀려 보임. 또한 초기화 버튼이 있는지, 사진 폴더를 다시 선택하면 리스트가 초기화되는지, 초기화하고 싶을 때와 기존 리스트에 이어붙이고 싶을 때 각각 어떻게 하면 되는지 질문
- **어떻게 처리했나**: 썸네일 폭을 캔버스 폭에 고정하고 파일명은 CSS 말줄임표(`text-overflow: ellipsis`)로 잘리게 처리. "사진 폴더 선택"(기존 리스트 비우고 새로 시작)과 별도로 "폴더 추가"(기존 리스트 유지한 채 뒤에 이어붙이기) 버튼을 새로 추가. 완전 초기화는 기존에 있던 "새로 시작(캐시 지우기)" 버튼으로 안내
- **결과**: Playwright로 긴 파일명 잘림, 폴더 추가 시 기존+신규 합쳐지는 것, "새로 시작" 시 리셋되는 것 모두 확인

### 매칭표 입력칸 답답해 보이는 문제 + 로고·텍스트 재질이 따로 노는 문제
- **무슨 문제/요청이 있었나**: 매칭표의 스토어명 입력칸이 패딩 없이 딱 붙어 답답해 보임. 또한 실제 렌더링 결과 스크린샷을 보내며, 스토어명 텍스트엔 흰 테두리가 있는데 옆의 PW 로고(비트맵)엔 테두리가 없어서 서로 재질이 다르게 보인다는 지적. 흰 테두리를 로고에도 넣으면 정신없어 보이고, 배경에 흰 네모를 씌우는 것도 어색해서 좋은 방법을 고민해달라는 요청
- **어떻게 처리했나**: 입력칸 패딩을 `2px` → `6px 8px`로 확대. 텍스트의 딱딱한 흰 테두리(`strokeText`)를 제거하고, 텍스트·로고 둘 다에 공통으로 부드럽게 퍼지는 흰 그림자(soft glow, `shadowBlur`)를 적용해 같은 재질처럼 보이게 통일
- **결과**: 어두운 배경/밝은 배경 두 종류 테스트 사진으로 렌더링해서 채팅으로 미리 보여준 뒤 반영. main 배포 확인은 아직 사용자 쪽에서 진행 중

### text-gradient(원본 그라데이션 도구) PNG 다운로드 파일명 자동화
- **무슨 문제/요청이 있었나**: text-gradient 메인 도구에서 PNG로 저장하면 `slot1.png`, `slot2.png`처럼 슬롯 번호로만 저장돼서 여러 장 받으면 서로 구분이 안 됨. 특수문자만 제거하고 한글은 그대로 살리는 안전한 파일명 생성 스니펫을 공유받음
- **어떻게 처리했나**: 슬롯의 제목(`titleL`/`titleR`, 화면엔 "titleL | titleR" 형태로 표시됨)을 조합해 `은혼_G.E.M. 시리즈.png`처럼 구분 가능한 파일명으로 저장하는 `safeFileName`/`slotFileNameBase` 함수 추가. 제목을 안 채운 슬롯은 기존처럼 `slotN.png` 유지
- **결과**: `slotFileNameBase` 함수를 직접 호출해 제목 조합·특수문자 제거·빈 제목 폴백까지 확인 (실제 다운로드 클릭은 이 검증 환경에서 html-to-image CDN이 막혀 있어 끝까지는 못 봤고, 로직 검증만 함 — 기존에도 있던 샌드박스 네트워크 제약)
